# Открытка для Даши

Небольшая открытка для телефона на HTML, CSS и JavaScript. Обложка открывается нажатием: внутри поздравление, жук с пожеланиями и сюрприз в духе Винкс. На компьютере открытка сохраняет компактный формат.

Сайт: [открытка для Даши](https://naf-fly.github.io/otkrytka-dashe/).

## Открыть

Двойным кликом откройте `index.html`. Установка и сборка не нужны.

Шрифты загружаются из Google Fonts; без интернета используются системные шрифты, все действия продолжают работать.

Для локального просмотра по адресу выполните в этой папке:

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:4173`.

## Изменить

Поздравление находится в `index.html`, в блоке `letter-text`. Пожелания жука — в массиве `wishes` в начале `script.js`. Цвета — в начале `styles.css`. Анимация Стеллы и её неподвижный кадр находятся в `assets/`.

Анимация — [Fairy Transformation от официального аккаунта Winx Club на GIPHY](https://giphy.com/gifs/Winx-Club-stella-winx-club-gvTITk4aovjVP6gUt6). Для современных браузеров используется лёгкий анимированный WebP, для остальных — GIF. При системной настройке уменьшения движения показывается неподвижный кадр.

Жук-почтальон оживает при нажатии и приносит раскрывающуюся записку. Шесть пожеланий выдаются в случайном порядке без повторов, пока не закончится набор. При уменьшении движения записка появляется сразу.

Перед появлением Стеллы проигрывается короткое превращение: искры собираются от кнопки в светящийся знак, затем раскрывается поздравление. Превращение можно отменить клавишей Escape. При уменьшении движения поздравление открывается сразу.

## Отправить

Можно отправить папку с файлами `index.html`, `styles.css` и `script.js` вместе с папкой `assets/`, сохранив их расположение. Чтобы смотреть по ссылке с телефона, загрузите их на статический хостинг. Телефонный предпросмотр вложений в мессенджерах может не выполнять JavaScript — нужен браузер.

Учтены безопасные отступы на телефонах и системная настройка уменьшения движения. Кнопки работают с клавиатуры, сюрприз закрывается крестиком, Escape, кнопкой внутри или нажатием за окном.
